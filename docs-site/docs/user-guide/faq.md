- Why don’t I see any infrastructure data?
  - Zoom in further or enable the layer in the Layers panel. Some layers load only within the current view.
- My export is blank or missing icons.
  - Wait a few seconds and try again. Large exports need time; enhanced sprites are loaded on demand.
- Overlapping zones pop up; which should I pick?
  - Smaller areas appear first. Use the popup list to choose or double‑click to pick the top area.
