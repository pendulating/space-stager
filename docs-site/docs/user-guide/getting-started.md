Welcome to Space Stager. This guide covers basics: supported browsers, navigation, and first map actions.

## Supported browsers

- Latest Chrome, Firefox, Safari.

## First steps

1. Open the app.
2. Pan/zoom the map, toggle basemap.
3. Search for a location.
4. Pick a geometry mode (Parks, Plazas, or Streets) based on your venue.
5. Select a permit area or street segment to focus.
