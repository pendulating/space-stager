title: Permit Areas

- Modes:
  - Parks Permit Areas: search by park name/property; focus by property/system.
  - DOT Plaza Areas: search by frontage street names; focus by feature id.
  - Intersections: block-by-block street network for street events.
- When you focus an area, the map centers and enables drawing/placement within bounds.
