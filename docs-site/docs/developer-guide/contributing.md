title: Contributing
---

- Dev setup: Node 24+, pnpm 9+, `pnpm install`
- Run app: `pnpm dev`
- Run tests: `pnpm test`
- Lint/format: `pnpm lint`, `pnpm format`
- Build docs: `pnpm run build:with-docs`
- PRs: small, focused changes; include tests where practical and update docs.
